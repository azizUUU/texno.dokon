Python Tilli

Python tili ilan (nilon) sharafiga emas, balki 1970-yillardagi mashhur "Monty Python" komedik
shousi sharafiga nomlangan. U Bugungi kunda Sun'iy Intellekt va Ma'lumotlar tahiil (Data
Science) sohasida eng yetakchi til hisoblanadi.

JavaScript Tili

JavaScript tili 1995-yilda Brendan Eich tomonidan bor-yo'g'i 10 kun ichida yaratilgan. Bugungi
kunda dunyoning barcha veb-saytlarning 98% dan ortig'i aynan ushbu tildan foydalanadi va ularni
interaktiv qiladi.

C++ Tilli

C++ tilli Bjarme Stroustrup tomonidan yaratilgan bolib, C tilining kengaytmasi hisoblanadi,
Kompyuter o'yinlari dvigatellari (Game Engies), kompyuter operatsion tizimlari (Windows,
MacOS) va brauzerlar aynan C++ da yoziladi.
